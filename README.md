# 💆‍♀️ Jéssica Costa — Estética e Bem-Estar

Landing Page e sistema web desenvolvido para **Jéssica Costa — Estética e Bem-Estar**, com integração entre frontend, API REST, banco de dados PostgreSQL e sistema de agendamento.

O projeto foi desenvolvido como **Projeto Integrador da Faculdade UNIVES-SP**, utilizando tecnologias modernas de desenvolvimento web, banco de dados e integração de APIs.

# 🎯 Objetivo do Projeto

O objetivo do projeto é desenvolver uma plataforma digital moderna para apresentação dos serviços de estética e bem-estar, permitindo que clientes conheçam os procedimentos disponíveis e realizem solicitações de agendamento.

A solução foi desenvolvida considerando:

- Experiência do usuário
- Design responsivo
- Organização das informações
- Integração com banco de dados
- Automação do processo de agendamento
- Arquitetura web moderna
- Separação entre frontend, backend e banco de dados

# 📅 Sistema de Agendamento

O cliente pode informar:

- Nome
- Telefone
- E-mail
- Serviço desejado
- Data
- Horário
- Observações

As informações são enviadas para a API através de uma requisição HTTP.

Fluxo:

```text
Cliente
   ↓
Formulário
   ↓
JavaScript
   ↓
API REST
   ↓
Node.js + Express
   ↓
PostgreSQL
   ↓
Supabase
```
