# Banco PostgreSQL

O arquivo `produtos_estetica.sql` cria somente a tabela de produtos solicitada para o consultório.

Campos principais:
- id_produto
- nome
- categoria
- marca
- unidade_medida
- estoque_atual
- estoque_minimo
- custo_unitario
- fornecedor
- ativo
- criado_em
- atualizado_em

A tabela pode ser expandida futuramente com movimentações de estoque, fornecedores, protocolos e consumo por atendimento.
